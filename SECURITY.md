# Security Policy

## Overview
This repository is a **skill repository** — a collection of knowledge, templates, and deep-dives. It is **NOT** a user-facing application or library, so its attack surface is minimal and client-side only.

## Supported Versions
The latest commit on `main` is the only actively supported version. Issues/PRs against old commits are closed unless critical.

## Reporting a Vulnerability
Since this repo contains prose and templates only, most "security" concerns are intentional content and not executable code.

- **Typo / Misleading content**: open an issue
- **Sensitive data leak / Malicious content**: DM @rafaumeu or email rafael.zendron22@gmail.com  — URGENT
- **Suggestions / General**: open a discussion or PR

## Do not file fake issues
Fake "vulnerability reports" wasting maintainer time are considered spam and will be closed and possibly flagged as abuse.

## Code of Conduct
This repo follows GitHub’s [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines). Disrespectful behavior or abuse of the issue tracker will result in summary rejection.
